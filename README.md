# 💰 بوت الكاش فلو (Cashflow Bot)

بوت تليجرام تسجل فيه **الوارد والمنصرف** بالكلام العادي أو بصورة الفاتورة أو PDF، وآخر الشهر تعرف حساباتك شكلها إيه.
أي حد يقدر يستخدمه، وكل مستخدم حساباته منفصلة ومتشفّرة.

مبني على [agunginsani/expenses-tracker](https://github.com/agunginsani/expenses-tracker) (رخصة MIT)، ومتعدّل علشان:
الوارد والمنصرف مع بعض، أكتر من مستخدم، عربي، جنيه مصري، وتوقيت القاهرة.

---

## البوت بيعمل إيه

| تكتب / تبعت | البوت بيعمل |
|---|---|
| جالي 15000 من مشروع المول | 🟢 وارد – أتعاب مشروع – مشروع المول |
| دفعت 500 بنزين | 🔴 منصرف – بنزين |
| اديت مروة 2000 ويحيى 100 | 🔴 حركتين منصرف، كل واحدة باسم صاحبها |
| صورة فاتورة / PDF | 🔴 منصرف بإجمالي الفاتورة (ولو اتبعتت مرتين ما بتتسجلش تاني) |
| 700 خالد | 🤔 يسألك: وارد ولا منصرف؟ |
| صرفت كام الشهر ده؟ | ملخص الشهر |
| مروة خدت كام؟ | كل اللي اديته لمروة الشهر ده بالتاريخ |

**الأوامر:** `/cashflow` · `/person مروة` · `/export` (ملف Excel) · `/undo` · `/deleteall` · `/help`

## الخصوصية باختصار
- كل حركة بتتحفظ **متشفّرة** (AES-256) في قاعدة بيانات Upstash، ومفتاح التشفير عندك أنت بس في Vercel.
- كل مستخدم بيشوف حساباته هو بس.
- الرسايل والصور بتتبعت لـ Gemini علشان تتقرا، ومش بنحتفظ بيها.
- `/deleteall` بيمسح كل بيانات المستخدم نهائياً.
- صفحة سياسة الخصوصية موجودة على `/privacy`.

# التشغيل

هتحتاج: **تليجرام، Google AI Studio (لمفتاح Gemini)، GitHub، Vercel**.

## 1) توكن البوت
افتح **@BotFather** في تليجرام، ابعتله `/newbot`، اختار اسم وusername ينتهي بـ `bot`، وخد التوكن.

## 2) مفتاح Gemini
ادخل **aistudio.google.com/apikey**، دوس **Create API key**، وانسخه.

## 3) Vercel
1. **vercel.com/new**، استورد الـ repo ده، ودوس **Deploy**.
2. **Storage ← Create Database ← Upstash for Redis ← Free**، واربطها بالمشروع.

## 4) المفاتيح
**Project ← Settings ← Environment Variables**:

| الاسم | القيمة |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توكن البوت |
| `GEMINI_API_KEY` | مفتاح Gemini |
| `WEBHOOK_SECRET` | كلمة سر عشوائية، حروف إنجليزي وأرقام بس |
| `ENCRYPTION_KEY` | 32 بايت عشوائية base64 (`openssl rand -base64 32`) |

وبعدين **Deployments ← ⋯ ← Redeploy**.

> ⚠️ `ENCRYPTION_KEY` ما تغيرهوش أبداً بعد التشغيل، وإلا الحسابات القديمة مش هتتقري.

## 5) اربط تليجرام (مرة واحدة)
افتح في المتصفح:
```
https://اسم-مشروعك.vercel.app/api/setup?key=WEBHOOK_SECRET
```
ولو ظهرت «✅ البوت اتربط بتليجرام»، افتح البوت واكتب `/start`.

### اختياري
- `ALLOWED_USER_IDS`: لو عاوز تقفل البوت على ناس معينة، حط أرقام تليجرام بتاعتهم مفصولة بفاصلة.
- `AI_DAILY_LIMIT`: عدد الرسايل اليومي لكل مستخدم (الافتراضي 60).

## للمطورين
```bash
bun install
bun test          # تواريخ، قراءة، تقارير، تخزين متشفّر، ورحلة البوت كاملة
bun run typecheck
```

```
api/webhook.ts          ← تليجرام بيبعت الرسايل هنا (متأمن بـ WEBHOOK_SECRET)
api/setup.ts            ← ربط تليجرام من المتصفح
src/bot.ts              ← كل الأوامر والرسايل والأزرار
src/services/ai.ts      ← Gemini: يفهم الرسالة (وارد/منصرف/سؤال) ويطلع JSON
src/services/ledger.ts  ← حفظ الحركات متشفّرة في Upstash
src/services/report.ts  ← ملخص الشهر وتقرير الشخص
src/services/excel.ts   ← ملف Excel للشهر
src/schemas/transaction.ts ← التصنيفات (عدّلها براحتك)
```

**أفكار للتطوير:** ربط اختياري بـ Google Sheets (النسخة الأولى موجودة في تاريخ الـ git)، تسجيل مروة صرفت الفلوس في إيه (تسوية العهدة)، رسايل صوتية، ميزانية شهرية وتنبيه، ملخص أسبوعي تلقائي.
